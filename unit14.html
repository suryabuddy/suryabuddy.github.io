अध्याय 14 - IT के उपयोगी अनुप्रयोग जारी

Restore point बनाने के लिए निम्न steps का प्रयोग किया जाता है :-

➢ Control Panel पर जाएं |

➢ System and Security पर क्लिक करें |

➢ System पर क्लिक करें |

➢ System Protection पर क्लिक करें |

➢ System Protection Tab पर क्लिक करें |

➢ Create बटन पर क्लिक करें |

➢ Restore point के लिए एक Description लिखें |

➢ उसके बाद create पर क्लिक करें |

Recycle bin को खाली करना :-

यह आपके कंप्यूटर का वह भाग है जहाँ आपके द्वारा delete की गयी फाइल्स रखी जाती हैं | Recycle bin को खोलने के लिए निम्न steps का प्रयोग किया जाता है :-

➢ Desktop पर Recycle bin icon पर double click करें |

➢ उसके बाद Recycle bin के window में सभी deleted files दिखाई देंगी |

➢ यदि आप किसी file को वापस लाना चाहते हैं तो उस पर right click कर Restore चुनें |

➢ यदि आप Recycle bin को खाली करना चाहते हैं तो Empty Recycle bin पर क्लिक करें |

Control Panel में मौजूद कुछ टूल्स और उनके उपयोग :-

Display :-

कंप्यूटर की display सेटिंग्स को कस्टमाइज़ करने के लिए इस कंट्रोल का उपयोग किया जाता है। जैसे - Screen Resolution, Brightness, Screen Saver आदि।

Taskbar and Navigation :-

Taskbar का प्रयोग desktop की position और taskbar पर दिखने वाले icons को customize करने के लिए किया जाता है।

Sound :-

कंप्यूटर के sound settings को बदलने के लिए इसका उपयोग किया जाता है। जैसे System Sounds, Playback, Recording आदि।

Date and Time :-

कंप्यूटर की Date और Time सेट करने के लिए इसका उपयोग किया जाता है।

Region and Language :-

कंप्यूटर में language और region settings को बदलने के लिए इसका उपयोग किया जाता है।

Font :-

कंप्यूटर में नए font install करने और पुराने font को delete करने के लिए इसका उपयोग किया जाता है।

Internet Options :-

Internet Explorer की settings को configure करने के लिए इसका उपयोग किया जाता है। जैसे Homepage, Security, Privacy, Connections आदि।

Device Manager :-

कंप्यूटर से जुड़े सभी hardware devices को देखने और उनके drivers को manage करने के लिए इसका उपयोग किया जाता है।

Devices and Printers :-

कंप्यूटर से जुड़े सभी printers, scanners और अन्य devices को देखने के लिए इसका उपयोग किया जाता है।

Programs and Features :-

कंप्यूटर में install किए गए सभी programs को देखने, उन्हें uninstall करने या बदलने के लिए इसका उपयोग किया जाता है।

Network and Sharing Center :-

Network connections को देखने, नई network बनाने और sharing settings को बदलने के लिए इसका उपयोग किया जाता है।

Windows Firewall :-

कंप्यूटर को unauthorized access से बचाने के लिए firewall settings को configure करने के लिए इसका उपयोग किया जाता है।

Windows Update :-

Windows के लिए latest updates को check करने और उन्हें install करने के लिए इसका उपयोग किया जाता है।
