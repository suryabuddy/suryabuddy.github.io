अध्याय 8 :- माइक्रोसॉफ्ट वर्ड

वर्ड प्रोसेसिंग और माइक्रोसॉफ्ट वर्ड का परिचय

वर्ड प्रोसेसिंग हमें टाइपिंग (Typing) एडिटिंग (Editing) फॉर्मेटिंग (Formatting) एवं किसी भी प्रकार की लिखित सामग्री को प्रिंट (Print) करने की सुविधा प्रदान करता है। हम दस्तावेजों को माइक्रोसॉफ्ट वर्ड के माध्यम से सहेज (Save) कर सकते हैं।

माइक्रोसॉफ्ट वर्ड एक वर्ड प्रोसेसिंग साफ्टवेयर (Software) है जो एप्लीकेशन साफ्टवेयर (Application Software) की श्रेणी में आता है इसे माइक्रोसॉफ्ट कम्पनी द्वारा विकसित किया गया है। माइक्रोसॉफ्ट वर्ड का मूल उद्देश्य लेटर टाइपिंग (Letter typing) रिपोर्ट (Reports) एवं विभिन्न प्रकार के डॉक्यूमेंट तैयार करना है यह आपको आपके लैपटॉप (Laptop), पर्सनल कंप्यूटर (Personal Computer) या होम कंप्यूटर पर डेस्कटॉप पब्लिशिंग (Desktop publishing) की सुविधा प्रदान करता है।

माइक्रोसॉफ्ट वर्ड 2019 शुरू करना

Start बटन पर क्लिक करें, All Programs पर क्लिक करें, इसके पश्चात् Microsoft Office पर क्लिक करें और उसके बाद Microsoft Word - 2019 पर क्लिक करने पर एक नया खाली डॉक्यूमेंट ओपन होगा।

या फिर आप कीबोर्ड से विंडो बटन के साथ R press करें और run बॉक्स में winword type और enter key press करें।

क्विक एक्सेस टूलबार (Quick access toolbar)

यह टूलबार फाइल टैब (File Tab) के बगल में होता है इस टूलबार में निम्न ऑप्शन्स होते हैं सेव (Save) (CTRL+S), अनडू (Undo) (CTRL+Z), रिडू (Redo) (CTRL+Y)। आप क्विक एक्सेस टूल बार को अपने उपयोग के अनुसार customize कर सकते हैं।

फाइल टैब (File Tab)

इस बटन के द्वारा सेव (Save), सेव एज (Save As), ओपन (Open), रीसेंट (Recent) और भी कई तरह के ऑप्शन का उपयोग किया जा सकता है।

Save As :- डॉक्यूमेंट को अलग फॉर्मेट्स जैसे वर्ड डॉक्यूमेंट, वर्ड 98 - 2003, वर्ड टेम्पलेट, पी.डी.एफ. (PDF) आदि में सेव करने के लिये।

Save :- जिस डॉक्यूमेंट पर आप कार्य कर रहे हैं यदि वह save किया हुआ नहीं है तो उसे save करने का अवसर प्रदान करता है।

Open :- पहले से सेव किये हुए डॉक्यूमेंट को ओपन करने की सुविधा प्रदान करता है।

Close :- वर्तमान में खुले हुए डॉक्यूमेंट को बन्द करने एवं बाहर आने की सुविधा देता है।

Info :- वर्तमान डॉक्यूमेंट जिस पर आप कार्य कर रहे हैं उसके बारे में सूचना देता है। व उस सूचना को सम्पादित करने तथा डॉक्यूमेंट का पासवर्ड बदलने के विकल्प प्रदान करता है।

Recent :- हाल ही में खोली गई फ़ाइलों को दोबारा खोलने का अवसर देता है। और ऐसी फाइल्स जो बार बार उपयोग में ली जा रही हो उनको पिन (Pin) करने में मदद करता है।

New :- यह बटन नया डॉक्यूमेंट बनाने के काम आता है इसमें ऑनलाइन टेम्पलेट में से कोई एक टेम्पलेट भी चुना जा सकता है।

Print :- यह बटन वर्तमान डॉक्यूमेंट को प्रिंट करने की सुविधा देता है। तथा प्रिंट प्रीव्यू (Print Preview) एवं प्रिंट सेटिंग (Print Setting) का अवसर भी देता है।

Save & Send :- यह ऑप्शन वर्तमान डॉक्यूमेंट जिस पर आप कार्य कर रहे हैं उसको save तथा send करने के काम आता है जैसे- Send as Attachment, Send as PDF, Send as Link, Send as XPS, Send as Fax, Send as Email आदि।

Help :- इस ऑप्शन के द्वारा माइक्रोसॉफ्ट ऑफिस के लिये हेल्प प्राप्त कर सकते हैं।

Exit :- इनके द्वारा माइक्रोसॉफ्ट वर्ड से बाहर निकला जा सकता है।

माइक्रोसॉफ्ट वर्ड 2019 में नयी फाइल बनाना एवं सेव करना

नया डॉक्यूमेंट बनाने के लिए File टैब पर क्लिक करें, New पर क्लिक करें, Blank Document पर क्लिक करें, Create बटन पर क्लिक करें। आप (ctrl+n) key प्रेस करके भी नया डॉक्यूमेंट बना सकते हैं।

डॉक्यूमेंट सेव करना - Quick Access Toolbar पर Save बटन पर क्लिक करें या Ctrl+S दबायें। File name बॉक्स में डॉक्यूमेंट के लिये एक नाम टाइप करें। अब Save बटन पर क्लिक करें।

Save As का उपयोग - File टैब पर क्लिक करें और Save As पर क्लिक करने पर Save As Dialog Box खुलता है। File name बॉक्स में इच्छित नाम को टाइप करें। Save As Type लिस्ट में इच्छित फाइल फॉर्मेट का चुनाव कर Save बटन पर क्लिक करें।

डॉक्यूमेंट को बंद करना - File tab पर click करें और फिर close पर क्लिक करें।

टेक्स्ट को सेलेक्ट करना

टेक्स्ट पर कुछ निश्चित कार्य / formating करने के लिए पहले text को select करना होता है।

एक वर्ड को सेलेक्ट करने के लिये उस वर्ड में कही भी डबल क्लिक करें। एक लाइन को सेलेक्ट करने के लिये लाइन के बायें ओर के Selection Area में क्लिक करें। एक पैराग्राफ को सेलेक्ट करने के लिये पैराग्राफ के सिलेक्शन एरिया में तीन बार क्लिक करें। पूरे डॉक्यूमेंट को सिलेक्ट करने के लिये Ctrl + A दबायें।

backspace व delete key का उपयोग करके एक बार में एक कैरेक्टर को डिलिट कर सकते हो। backspace key कर्सर के बायीं तरफ के अक्षरों को हटाता है। delete key कर्सर के दायीं ओर के अक्षरों को हटाता है।

टेक्स्ट को कॉपी कर एक स्थान से दूसरे स्थान पर ले जाना

टेक्स्ट कॉपी करने के लिए - home tab के clipboard ग्रुप में कॉपी बटन पर क्लिक करे या keyboard से ctrl+c प्रेस करें। डॉक्यूमेंट में आप जहाँ पेस्ट करना करना चाहते है वहाँ click करें। home tab के clipboard ग्रुप में paste बटन पर क्लिक करें या keyboard से ctrl+v प्रेस करें।

TEXT को एक स्थान से दूसरे स्थान पर ले जाना - जिस टेक्स्ट को आप मूव करना चाहते है उसे सेलेक्ट करें। होम टैब के clipboard ग्रुप में (cut) कमांड पर पर क्लिक करें या ctrl+x प्रेस करें। डॉक्यूमेंट में जहाँ आप टेक्स्ट paste करना चाहते है वहाँ क्लिक करें। home tab के clipbord ग्रुप में पेस्ट कमांड पर क्लिक करें या ctrl+v प्रेस करें।

अंडू करना - क्विक एक्सेस टूल बार में अंडू बटन पर क्लिक करें या ctrl+z key प्रेस करें। रिडू करना - क्विक एक्सेस टूल बार में रिडू बटन पर क्लिक करें या ctrl+y key प्रेस करें।

फॉन्ट, फॉन्ट स्टाइल, कलर व अन्य ऑप्शन का परिचय

Home टैब में कई प्रकार के ग्रुप हैं। clipboard, font, paragraph, style, editing आदि।

Clipboard Group:- Paste (Ctrl+v), Cut (Ctrl+x), Copy (Ctrl+c), Formate Painter

फॉन्ट ग्रुप में फॉन्ट की फॉर्मेटिंग से संबंधित ऑप्शन होते हैं - Font Style, Font Size, Bold, Italic, Underline, Strikethrough, Subscript, Superscript, Text highlight, Text colour

कैरेक्टर की फॉर्मेटिंग करना - इसमें फॉन्ट, फॉन्ट साइज, फॉन्ट स्टाइल, व इफेक्ट, और फॉन्ट कलर शामिल है। रिबन के home tab पर font में character की फॉर्मेटिंग की जा सकती है।

फॉन्ट बदलना - Home tab में font group में font एरो को क्लिक करें और लिस्ट में से अपनी इच्छानुसार फॉन्ट का चयन करें। Ms word 2019 में डिफॉल्ट फॉन्ट calibri होती है।

फॉन्ट साइज बदलना - फॉन्ट साइज को पॉइंट्स में मापा जाता है। Ms word 2019 में डिफॉल्ट फॉन्ट साइज 11 होती है। Home tab में font group में font size एरो को क्लिक करें और लिस्ट में से अपनी इच्छानुसार फॉन्ट साइज का चयन करें।

टेबल इन्सर्ट एवं डिलीट करना

सूचना को टेबल के माध्यम से बड़ी कुशलता के साथ संक्षिप्त व सरलता के साथ प्रस्तुत किया जाता है। Insert tab का चयन करें। Table group में टेबल विकल्प का चयन करें एक ड्रॉप डाउन मेनू दिखाई देगा। मेनू में स्क्रॉल के चयनित आकार की टेबल बना सकते हैं। उचित आकार मिलने पर आप क्लिक करें।

शेप्स को इन्सर्ट करना - वर्ड में shapes को insert करने के लिए insert tab में illustration ग्रुप में जाकर shapes ड्रॉप डाउन पर क्लिक करें। अब अपनी इच्छानुसार किसी एक shape का चयन करें। माउस से क्लिक करके माउस को ड्रैग ड्रॉप करें।

पिक्चर को इन्सर्ट करना - सेव की हुई picture को अपने वर्ड डॉक्युमेंट में insert करने के लिए insert tab के illustration ग्रुप में picture पर क्लिक करें। अब यहां से उस पिक्चर को सेलेक्ट करें जिसे आप अपने वर्ड डॉक्युमेंट में इन्सर्ट करना चाहते हैं। सेलेक्ट करने के बाद इन्सर्ट पर क्लिक करें। पिक्चर आपके वर्ड डॉक्युमेंट में दिखाई देने लगेगी।

3D मॉडल्स को इन्सर्ट करना - 3D मॉडल को इन्सर्ट करने के लिए insert tab के illustration ग्रुप में 3D मॉडल पर क्लिक करें।

टेक्स्ट बॉक्स को इन्सर्ट करना - टेक्स्ट बॉक्स को इन्सर्ट करने के लिए insert tab पर क्लिक करें। अब यहाँ से text group में text box icon पर क्लिक करें। Drop down मेनू में किसी एक प्रकार के text box का चयन करें। Text box आपके document में दिखाई देगा।

SmartArt Graphics - वर्ड में अनेक प्रकार के smartart graphics उपलब्ध है जिनके उपयोग द्वारा आप अपने विचार एवं योजनाओं को अनेक प्रकार से व्यवस्थित कर प्रदर्शित कर सकते हैं। अपने pointer को वहां रखें जहां आप document में graphics को insert करना चाहते हैं। Insert tab पर click करें। Illustration group में SmartArt command पर click करें। कई प्रकार के ग्राफिक्स दिखाई देंगे। उनमे से किसी एक ग्राफिक्स का चयन करें। चयनित ग्राफिक्स आपके पेज में दिखाई देगी।

हैडर एवं फुटर - हैडर और फुटर का प्रयोग उन चीजों को डॉक्युमेंट में प्रविष्ट करने के लिए होता है जिसे डॉक्यूमेंट में हर पृष्ठ पर दोहराया जाना हो। उदाहरण के लिए कंपनी का नाम, पेज नं. (पृष्ठ संख्या) आदि। Insert टैब पर क्लिक करें, हैडर फुटर Toolbar से हैडर या फुटर का चयन करें। जब आप Header/footer का चुनाव कर ले फिर उसे टाईप करे जिसे आप पृष्ठ (pages) पर दोहराना चाहते है।

बुकमार्क - किसी डॉक्युमेंट में स्थित एक लोकेशन स्थान अथवा एक टेक्स्ट सिलेक्शन को एक नाम द्वारा पहचान देने हेतु बुकमार्क (Bookmark) का प्रयोग किया जाता है। बुकमार्क जोड़ना - Insert Tab के Links ग्रुप में Bookmark का चयन करें। Bookmark Name के नीचे नाम टाईप करें। अब add button पर क्लिक करें।

Hyperlink - आप hyperlink का इस्तेमाल कर एक slide से दूसरे slide पर जा सकते है, network या internet के लिए तथा दूसरी file या दूसरे program के लिए hyperlink का इस्तेमाल कर सकते है। उस text को select करें जहाँ आप hyperlink एक्टिवेट करना चाहते है। Insert tab पर links group में hyperlink पर click करें। current folder या browsed pages का चयन करें। उस file को select जिसका आप hyperlink बनाना चाहते है और ok पर click करें। आपके द्वारा select किया हुआ text hyperlink में बदल जाएगा।

पैराग्राफ, एलाइनमेंट, बुलेट एवं नंबरिंग का परिचय - बुलेट लिस्ट (Bullet), ऑर्डर्ड/नम्बर्ड लिस्ट (Ordered / Number list), मल्टीलेवल लिस्ट (Multilevel list), इंडेंट घटाना / बढ़ाना (Decrease / Increase Indent), Align text left, center, Right, justify, Line & Paragraph Spacing, Paragraph Shading, Border

पैराग्राफ फॉर्मेटिंग - पेज पर एक पैराग्राफ के लेआउट (Layout) को प्रदर्शित करता है। इंडेंटेशन (Indentation), अलाइनमेंट (Alignment), लाइन स्पेसिंग (Line Spacing), स्पेस बिफोर पैराग्राफ, स्पेस आफ्टर पैराग्राफ को बदलकर आप पैराग्राफ के लुक को बदल सकते हैं।

पैराग्राफ अलाइन करना - Left और Right मार्जिन के बीच पैराग्राफ में टेक्स्ट की प्रत्येक लाइन की position को पैराग्राफ एलाइनमेंट कहते हैं।

Left Align - पैराग्राफ की प्रत्येक लाइन लेफ्ट मार्जिन पर अलाइन करता है डिफ़ॉल्ट अलाइनमेंट होता है। Center Align - पैराग्राफ की प्रत्येक लाइन को बीच में अलाइन करता है। Right Align - पैराग्राफ की प्रत्येक लाइन को राइट मार्जिन अलाइन करता है। Justify Align - पैराग्राफ की प्रत्येक लाइन और राइट मार्जिन के मध्य अलाइन करता है इससे लेफ्ट और राइट एज एक समरूप दिखाई देता है।
